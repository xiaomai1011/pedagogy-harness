# pedagogy-harness

> 挑战杯项目 · 科技发明制作 B 类（信息技术组）
> 第十九届"挑战杯"广东大学生课外学术科技作品竞赛 · 校内选拔赛 · 广州理工学院

**作品名称**：可插拔教学法组件对初学者 AI 编程学习效果的实证研究——一款教学法 Harness 练习助手的设计与验证

## 一句话说明

面向编程初学者的在线编程练习助手：学生在线做题、提交代码，系统自动判题后**不给答案**，
而是用一套可插拔的"教学法组件"循序渐进地引导，并自动记录全过程数据，
用于验证"到底哪种引导方式有效"。

## 自研边界（重要）

以下部分为团队**自研**，是本作品的创新点，答辩须能白板讲清：

- 教学法 Harness 约束层（包在大模型外的约束壳）
- 三个可插拔教学法组件：提示阶梯 / 错误分类器 / 学习者错误记忆
- 组件开关（用于对照实验与消融实验的分组控制）
- 判题运行器（subprocess + 超时，自行实现）
- 过程日志埋点

任何复用的第三方组件，均须在 [`docs/THIRD-PARTY.md`](docs/THIRD-PARTY.md) 中标注出处与许可证，
**不得作为自身创新点申报**。

## 开发原则

- **接口先行**：最早冻结判题模块对外契约（必须含 `error_type` 与 `stderr` 字段）
- **纵切打通**：先跑通单道题的端到端流程，再横向扩展
- **桩替换并行**：判题未就绪时用桩函数并行开发组件
- **日志先埋**：过程日志在开发初期同步实现，不得事后补录
