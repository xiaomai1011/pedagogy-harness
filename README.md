# 面向编程初学者的可插拔教学法练习助手的设计与实现

学生在网页里写 Python、提交判题，遇到问题时主动请求分级提示。项目复用现有模型和 Monaco 编辑器，自行实现教学组件、请求处理、输出检查、判题适配与事件记录。

代码仓库沿用技术标识 `pedagogy-harness`。当前应用版本为 `0.5.4-order`；本次名称与说明同步基于提交 `9ca3646`，没有重新发布版本或重跑历史验收。

## 当前项目方向

以系统设计、实现和工程验证为主，不再安排参与者招募、统一前后测或学习效果实验。历史试用方案保留用于追溯，不作为当前实施计划。

代码仍保留匿名身份、阶段顺序、题目权限和访问码能力。取消参与者实验没有删除这些功能，现有阶段限制仍按配置与代码执行。

## 主要功能

- **提示阶梯：**L1方向、L2思路骨架、L3伪代码、L4局部片段。连续失败提高可用等级，提示仍由用户主动请求；主动求助与连败解锁不重复叠加。
- **错误分类：**规则优先，按配置使用模型辅助；依据异常和测试信息关联可能涉及的知识点，证据不足时允许未分类或知识点为空。
- **错误记忆：**同一身份下跨题、跨会话累计错误类别和知识点。达到规则阈值后提供有限条提醒，延续依赖身份与存储条件。
- **可插拔组件：**统一接口、注册表和配置开关组织三个核心教学组件，另有辅助人格组件。
- **输出检查：**检查模型回复，必要时重试或返回保守提示，降低完整答案暴露的可能；不保证所有情况都能识别。
- **记录与导出：**代码提交、提示请求、回放和执行事件分别留痕；模型耗时与判题耗时分别记录。

缓存回放需要请求编号、身份、题目、批次和代码哈希匹配。符合条件时不重新调用模型、不升级；改代码后点击重看可能进入新处理路径。

## 判题怎样运行

受控提交路径由 FastAPI 服务检查身份、阶段和题目权限，再通过登记的 VM 适配器联系虚拟机 agent，由受限 worker 执行代码。

执行端配合低权限账户、独立任务目录、资源与时间限制、输出裁剪和任务清理。适配器不可用时停止受控判题，不自动改为宿主直接执行。普通本地子进程路径与 VM 路径的约束不同。

当前单路闸门是进程内的锁，按单 worker 部署理解，不是多实例共享锁。多租户隔离与并发容量没有因此得到验证。

## 身份与阶段配置

- `PH_AUTO_ENROLL=1` 且未强制访问码时，浏览器通过 Cookie 关联匿名编号，服务端不信任请求体自报身份。
- 清除 Cookie 或更换浏览器可能建立新身份，不按 IP 恢复原身份；IP仍可能用于排障。
- 当前匿名流程保留前测、练习、后测顺序及阶段结束锁定。前后测关闭教学提示，练习模式启用；这些是现存软件行为，不是当前项目安排的参与者实验。
- 访问码由 `PH_REQUIRE_ACCESS_CODE=1` 等配置启用。签名校验防止篡改，不阻止持有人转发。

## 本地启动

以下为 Windows PowerShell 命令。先准备 Python 和项目依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

仅在尚未创建 `.env` 时复制模板，再填写本地模型配置。已有配置不要覆盖。

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

打开 `http://127.0.0.1:8000/`。启动网页服务不等于 VM 和模型已就绪；判题需另外部署 VM agent、配置令牌并登记适配器，见[VM协议](docs/G4_VM_Agent_最小协议.md)。

默认数据库为 `data/demo.sqlite`，`use_real_db.txt` 会影响真实库选择，`PH_DB` 可配置路径。管理台位于 `/admin`，需本地管理令牌；详见[管理台说明](docs/G16_管理台说明.md)。验收使用独立数据与配置，不直接对现用数据执行写入型测试。

主要配置：

- `PH_LLM_BASE_URL`、`PH_LLM_API_KEY`、`PH_LLM_MODEL`：模型服务。
- `PH_LLM_REASONING_EFFORT`：可选参数，需 SDK 和模型服务支持。
- `PH_DB`：数据库路径。
- `PH_AUTO_ENROLL`、`PH_REQUIRE_ACCESS_CODE`、`PH_ACCESS_SECRET_FILE`：身份配置。
- `PH_VM_AGENT_ENABLED`、`PH_VM_AGENT_TOKEN_FILE`：VM适配器开关与令牌文件；其他连接参数见VM协议和适配器实现。
- `PH_ADMIN_TOKEN_FILE`：管理令牌文件。
- `PH_EXPERIMENT_MODE`、`PH_EXPERIMENT_BATCH`：沿用代码中的配置名，分别涉及调试信息限制与批次校验；名称不表示当前仍在组织实验。

## 目录与资料

- `app/`：服务端、组件、权限、流程与记录。
- `web/`：学生页面和管理台。
- `vm_agent/`：虚拟机agent、worker及部署单元。
- `data/questions/`：题库，包含内部用例和参考解。
- `tests/`、`tools/`：测试与核验工具，部分工具会写入数据。
- `docs/`：设计、契约与历史记录，参见[文档索引](docs/INDEX.md)。

## 数据与许可

代码、提交结果、身份编号、提示和运行事件可能被记录。匿名编号不等于真实人数，也不表示没有可关联信息。运行前应确定数据访问范围与保留期限。

真实密钥、令牌、数据库和导出数据不提交Git；题库包含隐藏用例和参考解，公开仓库前需另行检查发布内容。
