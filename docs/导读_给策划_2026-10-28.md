# 导读：给策划同学的实现说明（2026-10-28）

> 这份文档只讲「现在的代码是怎么实现的、验证到哪一步」。**不是实验结论，也不能当作学习效果证据。**
> 写答辩稿时请守住一句口径：**系统已有原型实现和工程验证证据；自动化测试通过、构造样例准确率、流程预演，都不等于真实学习效果已经得到证明。**

## 1. 版本

- 分支 `main`，本文档对应的最新提交见文末「版本锚点」（推送后填写）。
- 语言：Python 3.12+（本机运行用 3.14.7 的 venv），FastAPI + 原生 HTML/JS，无前端构建步骤。
- 数据：SQLite；题库在 `data/questions/*.json`（19 题：前测 3 / 练习 13 / 后测 3）。

## 2. 主链路（前端 → API → 教学组件 → VM 判题 → 数据）

1. **前端**（`web/index.html`）：选题目 → 写代码 → 提交 / 请求提示。
   - 访问码模式下身份由访问码决定，学生不需要填编号；页头区分「服务就绪」与「身份已验证」。
   - 提交与提示都带 `X-Access-Code`；429（服务忙）时不自动重试，保留代码。
2. **API**（`app/main.py`）：`POST /api/submit`、`POST /api/hint`。
   - 先用 `app/access.py` 验签访问码（身份、批次、有效期、可用阶段），再用 `_require_phase_allowed()` 按**服务端**题库里的阶段做二次约束；客户端传的 `phase` 不作数。
   - 单路执行闸门 `_SINGLE_LANE`：同一时刻只允许一个判题/提示请求，其余返回 429。
3. **教学组件管线**（`app/harness/pipeline.py`）：按配置串起各组件，产出最终反馈与事件记录；核心调用是
   `isolation.guarded_execute(isolation.registered_execution_adapter(), {...})`——**没有登记执行适配器时直接拒绝，退回不到宿主执行**。
4. **VM 判题**：
   - 宿主侧适配器 `app/harness/vm_agent_adapter.py` → HTTP `POST http://192.168.200.10:9443/v1/execute`。
   - VM 内 `vm_agent/ph_judge_agent.py`（以 `phagent` 身份监听，只校验/转发，不执行代码）→ 通过 Unix socket 交给
     `vm_agent/ph_judge_worker.py`（以 `phcode` 身份执行：独立临时目录、环境白名单、5 秒超时、杀整棵进程组、stdout/stderr 上限、结束清空工作目录）。
5. **数据**（`app/db.py`）：`submission_log`（提交与判题结果、代码原文）、`event_log`（请求级事件，含 `model_ms`/`exec_ms`）、
   `error_memory`（错误记忆）、`hint_state`（提示等级与回放）、`isolation_run_log`（隔离运行记录）。

## 3. 关键代码入口

| 主题 | 入口 |
|---|---|
| 提示阶梯 | `app/harness/hint_ladder.py`（`next_state` / `HintLadderComponent`）；等级规则见文件头注释 |
| 错误分类 | `app/harness/error_classifier.py`（`EVIDENCE_KP` 证据优先 + `CLASS_KP_KEYWORDS` 弱回退） |
| 错误记忆 | `app/harness/error_memory.py`（`MIN_COUNT=2`、`MAX_ITEMS=2`，只读展示、不另调模型） |
| 组件开关 | `app/harness/registry.py` 与 `pipeline.py` 的配置预设（`PRESETS`），可用 `PH_ALLOW_GROUP_SWITCH=0` 固定 |
| 访问码 | `app/access.py` + `tools/access_admin.py`（负责人本地签发，密钥只在仓库外的受保护文件里） |
| 隔离协议 | `app/harness/isolation.py`（`IsolationUnavailable`、`guarded_execute`、`DETAIL_CODES`） |
| 管理台 | `app/admin.py` + `web/admin.html`（本机访问、另需管理令牌；发题/看板/提交/事件/发码/CSV 导出） |
| 判题器 | `app/judge/runner.py`（契约见 `docs/contracts.md`） |

## 5. 还没完成的部分（答辩时要如实说）

1. **真实参与者实验尚未开始**：没有真实前后测数据，也没有学习效果结论。
2. **教师审核未完成**：分类样例与标签准则、L1–L4 代表性提示、前后测知识点/难度/评分标准，都需要教师复核并留下意见。
3. **实验组织未定**：参与者名单与知情同意、数据保存期限、固定匿名 ID、阶段窗口、发码流程、设备与时长安排。
4. **浏览器端人工核验**：目前完成的是 HTTP 级核验，跨设备页面操作仍需负责人按清单走一遍。
5. **隔离仍有已知边界**：单路受控部署下，同 UID 可造成短时服务中断、token 无自动轮换；不宣称生产级或多租户隔离。
6. **正式采集前的启动确认**：版本、正式库、批次、访问码强制、阶段权限、单实例、VM 就绪、备份，逐项核对后才开始。
