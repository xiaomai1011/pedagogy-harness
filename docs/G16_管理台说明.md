# G16 本机管理台（监控 / 发题 / 发码 / 导出）

日期：2026-10-28
定位：**负责人本机的操作与监控界面**，不是学生端页面。学生端仍是 `web/index.html`，行为不变。

## 1. 启动方式

管理台随同一个服务进程提供，默认入口 `http://127.0.0.1:8010/admin`。需要的环境变量：

| 变量 | 作用 | 说明 |
| --- | --- | --- |
| `PH_ADMIN_TOKEN_FILE` | 管理令牌文件路径 | 不配置 ⇒ `/admin` 与 `/api/admin/*` 全部 404（等于关闭管理台） |
| `PH_DB` | 服务连接的数据库 | 管理台读的就是这个库；界面上会显示绝对路径 |
| `PH_EXPERIMENT_BATCH` | 当前实验批次 | 发访问码时写进凭证，学生请求时服务端比对 |
| `PH_REQUIRE_ACCESS_CODE=1` | 强制访问码 | 正式采集必须开；不开时学生端不校验访问码 |
| `PH_ACCESS_SECRET_FILE` | 访问码签名密钥文件 | 与发码工具用同一把 |

桌面启动器（`start-window-gui.ps1`）在实验模式（launcher 目录存在 `experiment_db.txt`）下会自动：

- 设置 `PH_VM_AGENT_ENABLED=1`、`PH_VM_AGENT_TOKEN_FILE`、`PH_ADMIN_TOKEN_FILE`；
- 若存在 `experiment_batch.txt`，把内容当 `PH_EXPERIMENT_BATCH`；
- 若存在 `experiment_access.txt`，把内容（`1`/`0`）当 `PH_REQUIRE_ACCESS_CODE`。

## 2. 令牌与访问范围

- 令牌只从文件读，**不写进仓库、不进前端、不进导出**；页面上输入后仅存 `sessionStorage`。
- 仅接受来自 `127.0.0.1` / `::1` 的请求；其他来源一律 403 `admin_local_only`。
- 令牌不符 403 `admin_denied`；未配置令牌文件 404 `admin_disabled`。
- 管理台**不绕过**学生端的访问码与阶段校验：它只读写同一个库、同一套题目文件。

## 3. 功能

| Tab | 接口 | 说明 |
| --- | --- | --- |
| 进度看板 | `GET /api/admin/board` | 参与者 × 题目：次数 / 通过数 / 最高提示等级 / 最近活动 |
| 提交记录 | `GET /api/admin/submissions?participant_id=&question_id=&limit=` | 逐条提交（含错误分类、知识点、提示等级、判题耗时） |
| 事件日志 | `GET /api/admin/events?participant_id=&limit=` | `event_log` 原始事件（含 `model_ms`、`hint_source`、`judge_status`） |
| 发题 | `GET /api/admin/questions`、`POST /api/admin/publish` | 勾选发布/下架；学生端只看到已发布的题 |
| 发访问码 | `POST /api/admin/access-code` | 一人一个固定 ID、按阶段授权、1–72 小时 |
| 导出 | `GET /api/admin/export/{submissions\|events\|board}.csv` | UTF-8 BOM，Excel 直接打开不乱码；空表也带表头 |

### 发题语义（容易误解，写清楚）

- 发布表**从未使用**时：学生端按访问码阶段返回全部题目（本地联调）。
- 发布表**一旦有记录**：学生端只返回 `published=1` 的题目；即使把全部题下架，也只返回空列表——**不会悄悄退回全量可见**，避免"忘发题"时把前测/后测题暴露给练习阶段的学生。
- 因此正式实验前应先把该阶段要用的题发布，再发码。

### 访问码

- 由 `tools/access_admin.py issue --pid ... --batch ... --phase ...` 或管理台生成，格式 `v1.<payload>.<sig>`，HMAC-SHA256 签名。
- 无状态签名码**不能即时撤销**：阶段结束或需要统一作废时轮换 `PH_ACCESS_SECRET_FILE` 指向的密钥；不要为每个人切阶段重启服务。
- HMAC 只防伪造，**不防窃取与转发**；远程接入仍需传输保护，未具备前只做负责人监督下的本机核验。

## 4. 导出与备份

- 导出的是**当前服务连接的库**；原始库文件请另行复制备份。
- 不要靠删记录制造"干净库"；测试记录留在验收库里，正式库单独新建并在启动时确认路径。
