## 4. 撤销能力的真实含义

- 访问码是 **HMAC 无状态令牌**：服务端不保存签发记录，**不能即时撤销**；有效期内旧码一直可用（退出页面、收回纸条都不算撤销）。
- 阶段结束让旧权限失效的最小办法：**轮换签名密钥并重启服务**（所有旧码同时失效）；日常做法是**每阶段单独签发**、有效期只覆盖该阶段窗口 + 少量缓冲。
- 批次已真正生效：`PH_EXPERIMENT_BATCH` 与凭证里的 `batch` 不一致时返回 403 `batch_mismatch`（不再只是签进凭证）。

## 5. 仍有缺口 / 需负责人或教师完成

1. **远程访问**：本轮只监听 `127.0.0.1`。校园网访问需负责人确定设备、时间与受控传输方式；HMAC 不防窃取/转发，明文远程不得宣称安全。防火墙本轮未改。
2. **单进程锁的边界**：`threading.Lock` 只保护单进程；已确认当前只有 1 个监听实例、单 worker，但若将来起第二个实例（或改多 worker）需换跨进程互斥。
3. **教师复核**：错误分类标签、代表性提示样本、前后测题目知识点/难度/评分依据，仍需负责人组织教师审核；系统不得自动标"教师通过"。
4. **知情同意与保存期限**：未完成，正式采集前必须补齐。
5. **`accept_isolation` 两项集成检查**：仍未执行（exit 2）。它们的目标已由真实环境证据部分覆盖——真实 VM agent 判题通过、超时/派生进程/文件/网络/资源探针在 phcode 沙箱实测通过、隔离不可用拒判有真实 HTTP 证据（`judge_unavailable` + `isolation_run_log`）；但"集成脚本口径"本身未跑通，仍记为缺口，不追退出码。
6. **正式库切换**：验收库与正式库分离；正式切换是独立步骤，不通过删记录"清库"。

### 7.1 `model_ms` 的口径已统一

- 规则：**已确认本次请求没有模型调用 ⇒ 记 `0`；只有历史未采集的旧数据才是 `NULL`**，且不改写历史行。

- 影响范围：只是字段口径收尾，**不改变**"前测禁用提示"的行为结论。

### 7.2 浏览器验证与 HTTP 验证是两件事

- **已做（HTTP 级）**：首页返回的 HTML 含「实验访问码」「重看提示」「请求进一步提示」「服务正忙」等元素与文案；所有身份/阶段/回放/忙碌/导出检查都是真实 HTTP 请求。
- **未做（浏览器人工操作）**：没有在真实浏览器里手动点过"刷新 → 重看提示 → 切题 → 返回旧题"。`sessionStorage` 保存请求号与被试编号是**实现方式**，不等于已验证。
- 待办（一次人工核验即可，不新增自动化）：打开 `http://127.0.0.1:8010/`，确认 ①刷新后"重看提示"可点且回放同一条 ②切到另一题再回来，"重看"仍指向该题上一次提示 ③页面不把回放显示成新提示（不涨等级）。

### 7.4 访问码使用方式（负责人操作建议）

- 每阶段单独签发、有效期覆盖该阶段窗口 + 少量缓冲；**不要**每名学生切阶段就重启服务。
- 密钥轮换会**让所有旧码立即失效**（需重启），只用于统一批次切换或应急失效，不是日常操作。
- 无状态 HMAC **没有即时撤销**：退出页面/收回纸条都不会让旧码失效；新阶段开始前要确认旧阶段码已随有效期或密钥轮换失效。
- 正式实验前做一次发码/换阶段/失效的操作预演即可，不扩建账号平台。
