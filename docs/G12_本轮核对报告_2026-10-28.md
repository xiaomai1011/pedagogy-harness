## 二、申报承诺 ↔ 实现 / 证据 / 缺口

### 1. 提示阶梯（`app/harness/hint_ladder.py`，口径②-A）
| 场景 | 展示等级 | 解锁上限 |
|---|---|---|
| 首次主动请求（0 失败） | L1 | L1 |
| 无新增失败再次请求 | L1（不再升级） | L1 |
| 连续失败 2 / 3 次后请求 | L1 | L1 |
| 连续失败 4 次后请求 | L2 | L2 |
| 连续失败 6 次后请求 | L3 | L3 |
| 连续失败 8 次后请求 | L4 | L4 |
| 成功提交后（已解锁 L2） | L2（不回退） | L2 |
| 切题后 | L1 | L1 |
| 从未请求 | L0（不解锁不展示） | 不变 |

**与申报书原文的冲突（必须标注）**：原文为「须主动请求**或**连续失败 2 次才升级」。
现行实现里，「主动请求」只在**首次**把 L0 顶到 L1，之后请求**不再升级**；升级完全由连败驱动。
- 最小修正方案 A（推荐）：保持连败升级，同时允许「同一题累计主动请求 2 次」升一级（与连败取较大值），
  上限 L4——行为可解释、只改 `next_unlock` 入参与调用处。
- 最小修正方案 B：不改实现，改写申报书解释口径（但申报书不可改，故不推荐）。
未擅自修改行为，等负责人确认。

### 2. L1–L4 真实模型样本（`docs/G8_提示阶梯_L1-L4样本.json`）
- 4 条样本，题目 P001，每条独立参与者（避免连败累积），真实模型生成（`hint_source=llm`），
  无参考解泄漏（脚本比对参考解前缀，0 命中），客户端实测整请求 2.1–2.6 s。
- 分级性：L1 只给关键词（`range/len/split/int/max/index`）；L2 给步骤骨架 + 利用历史错误提醒；
  L3 给逐步伪代码；L4 给**局部片段**（`for` 循环骨架 + `pass` 占位），未给完整答案。
- 局限：单次采样，不能代表分布；重试/降级分支未覆盖（可用受控 stub 验证，不反复调模型）。

### 3. 错误分类准确率（`docs/G9_错误分类_人工标注评估.json`）
- 样例：**25 条**，五类各 5 条 + 2 条无错误场景；标签为**团队标注**（人工读代码与 traceback），
  **未经教师审核**，标签不取自系统预测。
- 结果：正确 **21**、错误 **4**、未分类 **0**，准确率 **84%**（分母含未分类）。
  规则命中 23/25，模型兜底 2/25。
- 典型错误：`int('abc')` / `'{'.format(1)` 被判「边界」（规则表把 `ValueError` 归边界），
  人工标为「类型」；2 条无错误场景被模型兜底强行分类（环境/逻辑）。
- 缺口：需教师复核标签；`ValueError` 的归类口径需定稿（转换失败算类型还是边界）。

### 4. 跨会话错误记忆（`docs/G10_错误记忆与组件开关证据.json`）
- 同一参与者 P001 错 2 次 → `error_memory('MEM-A','循环',count=2)`。
- `preventive_hint("MEM-A")` 返回「提醒一下：你此前反复出错的地方有 —— 逻辑类错误 2 次（知识点：循环）……」；
  另一参与者 `MEM-B` 返回空串（不串数据）。
- 独立子进程读取同一库可见该记录 ⇒ 记忆在库、不在进程内存（跨会话/重开页面成立）。
- 两次纯提示请求：`error_memory` 计数 1→1（不重复记账），`event_log` 4→8（有事件留痕）。

### 6. 提示等级 ↔ 通过率 ↔ 耗时（`tools/analyze_hint_outcomes.py`，`docs/G11_…json`）
- 已能按「同一参与者 + 同一题」关联：提示时间、等级、来源、**下一次正式提交及结果**、间隔。
- 三种时间口径：`submission_log.elapsed_ms`=判题耗时；`event_log.elapsed_ms`=提示请求整请求耗时（判题+模型）；
  `gap_seconds`=提示结束到下次提交的间隔（**不等于纯思考时间**）。
- 预演数据示例：L1 提示 1 次、下次提交通过率 1.0、间隔 0.0 s、判题 96 ms——**仅证明可算，属模拟数据**。
- 缺口：**没有单独的「模型耗时」字段**，判题与模型时长目前无法拆分。最小补丁（未实施）：
  `hint_ladder` 里对模型调用计时累加到 `ctx.model_ms`，`event_log` 增列 `model_ms`（含旧库 `ALTER TABLE` 迁移），
  `/api/hint` 回包带出该字段。
