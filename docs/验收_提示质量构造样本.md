## 0 修订说明：为什么有作废批次

批次 A 的夹具代码是：

```python
a = int(input())
print(a + b)
```

但 `P001` 题面要求输入**同一行空格分隔的两个整数**（如 `1 2`），于是第一行实际是 `int("1 2")`，
**会先抛 `ValueError: invalid literal for int() with base 10: '1 2'`**，
**根本到不了**第二行 —— 因此批次 A 注入的 `NameError: name 'b' is not defined`
与代码行为**不一致**，该批次**作废**——**不作为提示质量合格证据，仅保留为问题记录**。

- **保留原文**：批次 A 的提示正文**逐字保留**，未做任何改写。
- **一处发现的错误提示**：批次 A 的 L4 建议 `b = int(input())`，
  **不符合本题的单行输入格式**（题目不是两行各一个整数；再调一次 `input()` 在只有一行输入时还会 `EOFError`），
  对原代码也解决不了第一行的 `ValueError`。这是一处**真实的错误提示**。
- **撤回**：此前“L4 那一行与学生已有代码合起来正好是完整解”的说法**撤回**；
  “短题下局部片段可能直接补全答案”仍是**风险判断**，但**不能**用批次 A 这条错误修复当已证实的案例。
- **修正夹具**：批次 B 改用 `parts = input().split()` 版（第一行合法、第二行才触发 `NameError`），
  四级**共用同一份**夹具。
